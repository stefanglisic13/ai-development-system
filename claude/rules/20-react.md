# React Web Context

Apply only to web React apps. Do not apply web styling, DOM ids, or browser routing to React Native.

Before planning, implementing, or reviewing relevant work, read `.ai/standards/frameworks/react.md` in full and follow the approved project documents. The canonical standard contains the rules; this file only routes context.

The always-applied project-context rule requires this read even before source files exist. Resolve application boundaries from `.ai/STACK.md` and `.ai/STRUCTURE.md`; file extension alone does not determine the framework.
